# Console Java Programs

This repository contains a collection of small Java console-based programs created for learning and practice.

## Programs Included

- **BankAccount** – Simple class to simulate basic bank account operations.
- **Counter** – A program using threads to demonstrate counting logic.
- **DiscountCalculator** – Calculates discount based on user input.
- **Thread Communication (Restaurant Example)** – Demonstrates thread communication using Runnable.

### How to Run

1. Open any `.java` file in your IDE (like IntelliJ or VS Code).
2. Compile using:
   ```bash
   javac FileName.java
   java FileName
